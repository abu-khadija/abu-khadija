## About me

I build test automation for enterprise SaaS and mobile products, and I direct AI coding agents to cover more ground than manual scripting can, while I own the design, the review and the results.

- 🧪 **3.5+ years in QA** across regulated-industry EHSQ platforms, document management and consumer mobile apps
- 🏗️ **Sole QA on a North American team.** I built QA from zero for two products, from test strategy to automated CI
- 🤖 **Designed an agentic QA plugin for Claude Code** that turns pull requests and Jira tickets into risk-based test plans (20 changes → 86 test cases in ~6 minutes), with safety guardrails on every action
- 📊 **Migration regression across 15 modules:** 1,150+ test cases, 113 defects reported, 97 fixed
- 📱 **Playwright + TypeScript framework:** 150+ tests running on Web, iPad and iPhone; 5 iOS-only defects caught before release
- 🔐 Security, permission-matrix, k6 load and visual-regression testing
